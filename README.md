# Mechanical Safe

Курсов проект по дисциплината „Компютърна графика“, представляващ интерактивна 3D техническа визуализация на механичен кодов сейф с анимиран заключващ механизъм.

## Реализирани графични техники

- самостоятелно генерирани mesh-ове за куб и цилиндър;
- йерархични трансформации: врата около панта, дискове около собствени оси, дръжка и болтове на вратата;
- перспективна и ортогонална проекция;
- орбитална камера;
- Phong/Blinn-Phong осветление с метални материали и процедурен ефект на шлифован метал;
- плавни анимации, независими от честотата на кадрите;
- разглобен технически изглед, който показва вътрешната заключваща пластина.
- вътрешно отделение със стоманен рафт и златни кюлчета, видимо след отключване.

## Контроли

|         Клавиш      |              Действие             |
|---------------------|-----------------------------------|
| `1`, `2`, `3`       | Избира кодов диск                 |
| `A`, `D`            | Завърта избрания диск             |
| `Enter`             | Проверява комбинацията            |
| Стрелки             | Завърта камерата около сейфа      |
| `W`, `S` или scroll | Приближава/отдалечава камерата    |
| `P`                 | Перспективна/ортогонална проекция |
| `T`                 | Технически разглобен изглед       |
| `F`                 | Wireframe режим                   |
| `R`                 | Нулира демонстрацията             |
| `H`                 | Показва контролите в конзолата    |

Демонстрационната комбинация е „4-7-2“.
